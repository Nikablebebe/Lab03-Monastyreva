ОТВЕТЫ НА ВОПРОСЫ

1. разницы в результате нет, это одно и то же. просто x += 5 это сокращенная запись
2. х++ - сначала использует старое значение х в выражении, а потом увеличивает его на 1
++х - сначала увеличивает х на 1, а потом использует новое значение
3. всегда bool. результат может быть только true или false
4. для && - если первая часть false, то все выражение уже false и вторая часть не проверяется
для || - если первая часть true, то все выражение уже true  и вторая часть не проверяется. 
простыми словами короткое замыкание это когда компьютеру лень проверять вторую часть условия, потому что уже знает ответ по первой.
привер:
я спрашиваю у друга "ты поел И поспал?"
если он отвечает "я не поел", то я уже знаю, что ответ на ВСЁ выражение НЕТ. зачем спрашивать про сон, если уже все равно false
если отвечает "я поел", тогда надо спросить про сон, ведь ответ зависит от второй части

   2 - сложение и вычиьание +, -
